| Python library: venv, creation of virtual environments | https://docs.python.org/3/library/venv.html | 2026-11-10 | `python -m venv <folder>` creates a virtual environment; the activation commands for POSIX shells (`source <venv>/bin/activate`) and Windows (`<venv>\Scripts\activate`); `deactivate`; `sys.prefix` differs from `sys.base_prefix` inside a virtual environment; virtual environments are not portable and should be recreated rather than copied or moved; in PowerShell the script is `<venv>\Scripts\Activate.ps1`, and running it may first need `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`. |
| Python tutorial: Virtual Environments and Packages | https://docs.python.org/3/tutorial/venv.html | 2026-11-10 | A virtual environment gives each application its own installed packages; `python -m pip install`, `pip list`, `pip show`, `pip freeze > requirements.txt` and `pip install -r requirements.txt`. |
