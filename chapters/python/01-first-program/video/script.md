# Video Script: Chapter 1, Your First Program and Your AI Study Partner

Target length: about 4 minutes. Format: landscape 1920x1080. Uses only code and output verified in this chapter.

## Scene 1: Hook

**Duration:** 20 seconds

**Narration:** An AI assistant wrote this line of code. It runs with no error. But it is wrong. By the end of this video, you will see why, and you will write your first real program.

**On screen:** The code `print("2026", "11", "09")` and its output `2026 11 09`, next to the request "Print the date as 2026-11-09". A red circle appears around the spaces.

**Interaction:** On-screen question: "Can you spot the problem?" A three-second countdown.

## Scene 2: Why

**Duration:** 25 seconds

**Narration:** Every app you use is a program: a list of instructions that a computer follows exactly. AI tools can write those instructions now. They are often right. Sometimes they are wrong and still sound sure. Your job is to understand the code and check the result.

**On screen:** Three simple icons: a calculator, a checkout screen and a timetable. Each one turns into lines of code.

**Interaction:** None. The progress map shows "Chapter 1 of 28".

## Scene 3: Mental model

**Duration:** 30 seconds

**Narration:** A Python program is a text file. Python reads it from top to bottom and runs one line at a time. Think of a recipe, with one difference: a cook can guess what you meant, but Python cannot.

**On screen:** The diagram from "The idea": a file, an arrow to "Python reads", an arrow to "The computer acts". A highlight moves down the lines one at a time.

**Interaction:** None.

## Scene 4: Build

**Duration:** 60 seconds

**Narration:** Open a code editor and type two print lines. Run the file. Each print makes one line of output. Now three steps for making tea. Before we run it, predict the order. Then we add two settings: sep goes between values, and end goes after the last one.

**On screen:** `ex01_hello.py` typed line by line, then its output. Then `ex02_order.py`, then `ex03_many_values.py`, with `sep` and `end` highlighted.

**Interaction:** Pause card: "Predict the output of ex03 line 4 and 5. Pause the video now." A five-second countdown, then the reveal: `Loading...done`.

## Scene 5: Outcome

**Duration:** 30 seconds

**Narration:** Put it together and you get a receipt. Python lines up the dots with sep and calculates the total for you.

**On screen:** `ex04_receipt.py` on the left, its output on the right. The lines `1 + 1` and `3 + 7` highlight, then their results `2` and `10` glow in the output.

**Interaction:** On-screen question: "Which lines did Python calculate?"

## Scene 6: AI pair moment

**Duration:** 40 seconds

**Narration:** Back to the opening puzzle. The AI forgot that sep is a space by default. Code that runs is not always correct. Compare the output with the request, character by character. Add sep equals hyphen, and the date is right.

**On screen:** `ai_date_flawed.py` and its output, then the fix `ai_date_fixed.py` and the output `2026-11-09`. Then the three safety habits as a checklist: no private data, run and check, you are responsible.

**Interaction:** On-screen question: "Write down the fix before it appears." A four-second countdown.

## Scene 7: Think beyond

**Duration:** 25 seconds

**Narration:** Errors are messages, not failures. Read the last line first. It names the problem. Here is a capital P in Print. Python even suggests the fix. Now think: how could one print show a shopping list on several lines?

**On screen:** `err02_capital_p.py` and its error, with the last line highlighted. Then the question card.

**Interaction:** Prompt: "Try it, then post your idea in the comments."

## Scene 8: Recap

**Duration:** 20 seconds

**Narration:** A program runs top to bottom. Print shows values. Sep and end control spacing. Errors tell you the kind and the line. AI explains, and you check. You earned 100 XP and the First Run badge. Next, variables.

**On screen:** Four recap lines appear one by one. The XP bar fills to 100. The First Run badge appears. The progress map moves to Chapter 2.

**Interaction:** End card: "Do the warm-up tasks now. They take ten minutes."
