# Python Chapter 10: Boss Level 2, The Number Guessing Game

A typed word crashes a program that trusts every answer. Follow Asha as she plans, builds and tests the Corner Cafe biscuit jar game: a random secret from 1 to 20, five tries with hints, and answers checked with strip and isdigit before int. She uses an AI assistant at all six stages and catches two confident AI mistakes with tests: randrange(1, 20) never picks 20, and removing strip rejects 7 with a space.
