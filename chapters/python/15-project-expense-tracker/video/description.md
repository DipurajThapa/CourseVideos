# Python Chapter 15: Boss Level 3, The Expense Tracker

At closing time, nobody at the Corner Cafe knows where the money went. Follow Asha as she plans, builds and tests an expense tracker with a list of tuples, a set of categories, checked amounts and a dictionary of totals. She uses an AI assistant at all six stages. Tests catch three confident AI mistakes: a model that loses data, max() on a dictionary, and a shorter line that crashes.
