# Code Quest: Learn to Code with AI

Code Quest is a practical, gamified programming course that teaches two skills together: how to write code, and how to use an AI assistant such as ChatGPT or Claude at every stage of building software. Learners focus on understanding each concept and applying it step by step, not on memorising syntax.

The first course is **Code Quest: Python**. It has 28 chapters in 6 modules, and each module ends with a boss-level project.

## Who it is for

- Complete beginners aged 15 and over, with no coding experience.
- People who already use a chat AI and want to build real programs with it, safely and with good judgement.
- Learners who read English as a second language. Every lesson uses short sentences and plain words.

By the end of the Python course, a learner can write small, useful programs, test them, and work with an AI assistant at every stage of the work: plan, write, generate, test, debug and improve.

## How a chapter works

Each chapter follows Asha, who helps at her family's Corner Cafe. Every chapter adds one skill to her cafe programs, starting with a printed receipt and ending with a complete task manager.

- **Lesson:** the idea, a step-by-step build, the finished program, common mistakes and a recap. Every code example has been run, and its exact output is shown.
- **Work with AI:** six prompt cards, one for each stage: plan, write, generate, test, debug and improve. Each chapter has an "AI pair moment": a realistic AI answer with a hidden flaw that you find and fix.
- **Practice:** 8 tasks in three tiers (3 warm-up, 3 apply, 2 stretch) for 170 XP, each with a tested solution.
- **Video:** a narrated walkthrough of the whole chapter, about 15 to 19 minutes long. Questions stay on screen with a 10-second timer so you can predict before you see the answer, and short breathers recap what you have learned.
- **Rewards:** 100 XP and a badge for each lesson; 300 XP for each boss level.

## How to use the course

1. Install Python 3.12 or newer from [python.org](https://www.python.org/downloads/).
2. Open a chapter below. Watch its video, or read its lesson, or both.
3. Type the examples yourself and run them. Predict each output before you run the code.
4. Do the practice tasks before you open the solutions.
5. Use the prompt cards with your AI assistant, and check every answer it gives by running the code.

Never paste passwords, keys or private data into an AI tool. You are responsible for the code you use, even when an AI wrote it.

## What each chapter folder contains

```text
chapters/<language>/<NN>-<slug>/
  lesson.md              the chapter (project.md for boss-level projects)
  examples/              every runnable example with its verified .expected output
  ai-prompts.md          six prompt cards: plan, write, generate, debug, test, improve
  practice/              8 tasks in three tiers, with verified solutions
  video/chapter.mp4      the narrated full-chapter video (1080p, captions, scene markers)
  video/storyboard.json  the video direction: scenes, narration and what is on screen
  video/script.md        the script with timings, generated from the storyboard
  video/chapter.srt      captions; video/description.md is the upload text
  sources.md             sources, access dates and what each one confirmed
  meta.json              metadata, changes and outstanding issues
  verification.json      machine-written proof of what was tested, when and on what
```

## How the repository works

1. `tools/state.py next` picks the next item: resume unfinished work, apply requested changes, start the next chapter, or build the next language's curriculum.
2. The chapter is researched on official documentation and other credible sources, then written on a `wip/<chapter-id>` branch.
3. `tools/render_video.py` turns the storyboard into the narrated video.
4. `tools/verify_chapter.py` runs every example and solution, checks the lesson code against the tested files, checks structure, sources and plain-language rules, and checks that the video matches the verified files.
5. Only a fully passing chapter is merged into `main` with the status "ready for review", and a report lands in `reports/`.
6. `tools/build_course_index.py` refreshes the course table above.

Full procedure: [`RUNBOOK.md`](RUNBOOK.md). Content rules: [`STANDARDS.md`](STANDARDS.md). Video style: [`.claude/skills/code-quest-video/SKILL.md`](.claude/skills/code-quest-video/SKILL.md). Live progress: [`state/progress.json`](state/progress.json) and [`REVIEW.md`](REVIEW.md).

## Reviewing

Open [`REVIEW.md`](REVIEW.md), read the chapter and watch its video, then:

```bash
python3 tools/state.py approve python-01
python3 tools/state.py request-changes python-02 "Use a shopping example instead of the bank example"
```

Approved chapters are never edited by a run. If later research finds a problem in one, the run writes a proposal to `corrections/` for you to accept or reject.

## About the narration

The videos use a synthetic voice: Kokoro-82M (open source, Apache-2.0), voice `bm_lewis`. Every on-screen code example, output and error comes from a file that the verification tool has run.
