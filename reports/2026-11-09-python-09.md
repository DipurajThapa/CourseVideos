## What was built
- **Lesson:** the three kinds of bugs (syntax, runtime, logic), reading a traceback from the bottom up, the cause on an earlier line than the one Python names, print debugging, and a four-part debugging prompt (code, exact error, expected result, actual result).
- **Common mistakes:** a missing comma (SyntaxError with Python's suggestion), a variable used before it exists (NameError), a debug line with the wrong indentation (IndentationError) and a decimal comma typed by the user (ValueError).
- **Story:** Asha's end-of-day report prints a total that is too small, with no error. Her mission is a report she can trust.
- **Work with AI:** all six stages work on a day with 0 sales.
  - Plan: a bug-hunting plan with no code. Write: Asha reads the traceback herself and asks the AI to check her reading.
  - Generate: the AI's check `if sales >= 0:` still divides by zero, although it promised "No sales today.".
  - Test: three cases with expected results; 0 sales fails. Debug: the structured prompt finds the cause on line 8; every case runs again after the fix.
  - Improve: the AI suggests keeping a debug line, which changes the output against Asha's instruction.
- **Practice:** 8 tasks, 170 XP. **Examples:** 23 verified files, including video-only AI files.
